# تمرین‌های سی‌شارپ

![C#](https://img.shields.io/badge/C%23-239120?logo=csharp&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)

Six small C# console exercises from university coursework. Each file has its own `Main` and runs on its own.

شش برنامه کنسول از تمرین‌های دانشگاه. هر فایل یک `Main` جدا دارد و باید تنها اجرا شود.

| فایل | کار |
| --- | --- |
| `کنکور.cs` | بررسی مجاز بودن سن برای کنکور |
| `نمره.cs` | دسته‌بندی نمره از ۰ تا ۲۰ |
| `مقایسه اعداد.cs` | پیدا کردن بزرگ‌ترین عدد بین سه عدد |
| `مساحت ها.cs` | مساحت دایره، مثلث و مستطیل |
| `سال تولد.cs` | گروه سنی از روی سال تولد |
| `بخش پذیری.cs` | بررسی بخش‌پذیری |

.NET 10. برای دیدن یک فایل:

```bash
dotnet new console -n one -o one
```

بعد محتوای همان فایل را به‌جای `Program.cs` بگذارید و `dotnet run --project one` را بزنید.
